# UI Components

Generic, game-agnostic primitives, styled exclusively from
`app/tokens.css` — no raw hex, no per-instance color. No game-specific or
platform-specific logic lives here. The mandatory set (`ADR-0004` §2):
`Button`, `Card`, `Field`, `CodeInput`, `PlayerChip`, `Screen`,
`RevealCard`, `Scoreboard`, `WaitingState`. See
`docs/05_engineering/CONVENTIONS.md` and `docs/00_decisions/architecture/ADR-0004-DESIGN-SYSTEM-CONTRACT.md`.
